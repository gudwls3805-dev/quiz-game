# 나만의 퀴즈 게임 🎯

터미널에서 즐기는 **영화 주제 4지선다 퀴즈 게임**입니다.
Python 기본 문법과 클래스(객체 지향 프로그래밍), JSON 파일 저장을 활용해
퀴즈를 풀고, 직접 문제를 추가하고, 최고 점수를 기록할 수 있습니다.

## 프로젝트 개요
- 프로그램을 실행하면 메뉴가 나타나고, 번호를 선택해 기능을 이용합니다.
- 퀴즈를 풀면 문제마다 정답/오답을 판정하고, 마지막에 총점을 보여줍니다.
- 사용자가 새 퀴즈를 등록할 수 있으며, 등록한 퀴즈와 최고 점수는
  **`state.json` 파일에 저장**되어 프로그램을 종료한 뒤 다시 켜도 그대로 유지됩니다.
- 외부 라이브러리 없이 **Python 표준 라이브러리만** 사용했습니다.

## 퀴즈 주제와 선정 이유
- **주제:** 영화
- **선정 이유:** 대중적인 영화로 퀴즈 문제를 만들면 풀기도 쉽고 다가가기 편할 것 같아 선정했습니다.

## 실행 방법
```
python main.py
```
- Python 3.10 이상 필요
- 별도 설치 없이 바로 실행 가능 (표준 라이브러리만 사용)
- 첫 실행 시 저장 파일이 없으므로 기본 영화 퀴즈 5문제로 시작합니다.

## 기능 목록
| 번호 | 기능 | 설명 |
|----|------|------|
| 1 | 퀴즈 풀기 | 저장된 문제를 차례로 출제하고 정답/오답을 판정, 마지막에 점수를 표시하고 최고 점수를 갱신합니다. |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호(1~4)를 입력받아 새 퀴즈를 등록하고 파일에 저장합니다. |
| 3 | 퀴즈 목록 | 등록된 모든 퀴즈의 문제를 번호와 함께 보여줍니다. |
| 4 | 점수 확인 | 최고 점수를 확인합니다. (아직 풀지 않았으면 안내 메시지 출력) |
| 5 | 종료 | 프로그램을 종료합니다. |

## 코드 구조
기능별로 역할을 나눈 **2개의 클래스**로 구성되어 있습니다.

### `Quiz` 클래스 — 퀴즈 1개를 표현
- **속성:** `question`(문제), `choices`(선택지 4개), `answer`(정답 번호 1~4)
- **메서드:**
  - `show()` — 문제와 선택지를 화면에 출력
  - `is_correct(user_answer)` — 입력한 번호가 정답인지 True/False로 반환
  - `to_dict()` — 저장을 위해 객체를 dict 형태로 변환

### `QuizGame` 클래스 — 게임 전체를 관리
- **속성:** `quizzes`(퀴즈 목록), `best_score`(최고 점수)
- **메서드:**
  - `show_menu()` — 메뉴 출력
  - `play_quiz()` — 퀴즈 진행 및 채점, 최고 점수 갱신
  - `add_quiz()` — 새 퀴즈 등록
  - `show_list()` — 퀴즈 목록 출력
  - `check_score()` — 최고 점수 확인
  - `save()` / `load()` — state.json 저장·불러오기
  - `run()` — 메뉴 반복 실행(게임 시작점)

## 입력 및 예외 처리
- 숫자 입력 시 앞뒤 공백을 제거(`strip`)하고, 허용 범위(메뉴 1~5, 정답 1~4)를 벗어나거나
  숫자가 아니거나 빈 값일 경우 안내 메시지를 출력한 뒤 다시 입력받습니다.
- 저장 파일이 **없을 때**는 기본 퀴즈로 시작하고, 파일이 **손상**되었을 때는
  `try/except`로 오류를 잡아 기본 데이터로 복구합니다.

## 데이터 파일 설명 (state.json)
- **경로:** 프로젝트 루트의 `state.json`
- **역할:** 퀴즈 목록과 최고 점수를 저장해, 프로그램을 종료해도 데이터가 유지됨 (데이터 영속성)
- **인코딩:** UTF-8 (한글이 깨지지 않도록 저장)
- **생성 시점:** 퀴즈를 추가하거나 풀어서 점수가 바뀔 때 자동으로 저장됨
- **스키마:**
```json
{
    "quizzes": [
        {
            "question": "문제 내용",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 2
        }
    ],
    "best_score": 1
}
```
- `quizzes`: 퀴즈 목록 (각 퀴즈는 문제·선택지·정답 번호를 가짐)
- `best_score`: 최고 점수 (아직 풀지 않았으면 `null`)
- 파일이 없으면 기본 퀴즈 데이터로 시작하고, 손상된 경우 기본 데이터로 복구합니다.

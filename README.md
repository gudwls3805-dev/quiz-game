# 나만의 퀴즈 게임 🎯

터미널에서 즐기는 **영화 주제 4지선다 퀴즈 게임**입니다.
Python 기본 문법과 클래스(객체 지향), JSON 파일 저장을 활용해 만들었습니다.

## 저장소 정보
- **GitHub:** https://github.com/gudwls3805-dev/quiz-game

## 프로젝트 개요
- 실행하면 메뉴가 나타나고, 번호를 선택해 퀴즈 풀기/추가/목록/점수/종료를 이용합니다.
- 추가한 퀴즈와 최고 점수는 `state.json`에 저장되어 종료 후 다시 켜도 유지됩니다.
- 외부 라이브러리 없이 Python 표준 라이브러리만 사용했습니다.

## 퀴즈 주제와 선정 이유
- **주제:** 영화
- **선정 이유:** 대중적인 영화로 퀴즈 문제를 만들면 풀기도 쉽고 다가가기 편할 것 같아 선정했습니다.

## 실행 방법
```
python main.py
```
- Python 3.10 이상 필요 (표준 라이브러리만 사용)
- 첫 실행 시 저장 파일이 없으므로 기본 영화 퀴즈 5문제로 시작합니다.

### 기본 퀴즈 변경 방법
- 기본 퀴즈는 `main.py`의 `QuizGame.__init__` 안 `self.quizzes` 리스트에 정의돼 있습니다.
- `Quiz("문제", ["선택지1", "선택지2", "선택지3", "선택지4"], 정답번호)` 형식으로 줄을 추가/수정합니다.
- 이미 `state.json`이 있으면 저장된 데이터가 우선하므로, 기본값으로 초기화하려면 `state.json`을 삭제 후 재실행하세요.

## 기능 목록
| 번호 | 기능 | 설명 |
|----|------|------|
| 1 | 퀴즈 풀기 | 문제를 차례로 출제·채점하고 총점 표시, 최고 점수 갱신 |
| 2 | 퀴즈 추가 | 문제·선택지 4개·정답 번호를 입력받아 등록 후 저장 |
| 3 | 퀴즈 목록 | 등록된 퀴즈 문제를 번호와 함께 표시 |
| 4 | 점수 확인 | 최고 점수 확인 (미플레이 시 안내) |
| 5 | 종료 | 프로그램 종료 |

## 코드 구조
기능별로 역할을 나눈 **2개의 클래스**로 구성됩니다.

### Quiz 클래스 — 퀴즈 1개를 표현
- **속성:** `question`, `choices`(4개), `answer`(1~4)
- **메서드:** `show()`(출력), `is_correct(n)`(정답 여부 bool 반환), `to_dict()`(저장용 dict 변환)
- **인터페이스:** 입력은 (문제·선택지·정답), 출력은 화면 출력 또는 True/False

### QuizGame 클래스 — 게임 전체 관리
- **속성:** `quizzes`(목록), `best_score`(최고 점수)
- **메서드:** `show_menu`, `play_quiz`, `add_quiz`, `show_list`, `check_score`, `save`/`load`, `run`
- **인터페이스:** 사용자 입력을 받아 Quiz 객체들을 다루고, 결과를 화면/파일로 출력

### 클래스로 분리한 이유 (재사용성)
- `Quiz`는 "문제 1개" 단위를 캡슐화해, 문제 수가 늘거나 **다른 주제로 바꿔도 같은 틀로 재사용**됩니다. (영화 대신 역사 퀴즈를 넣어도 `QuizGame`은 수정 불필요)
- `QuizGame`은 흐름·데이터 관리를 담당해, 기능 추가(삭제·힌트 등) 시 **메서드만 추가**하면 됩니다.

## 입력 및 예외 처리
- **입력 검증:** 앞뒤 공백 제거(`strip`), 숫자 아님/범위 밖/빈 입력 시 안내 후 재입력(메뉴 복귀).
- **재시도 정책:** 횟수 제한 없이 올바른 입력이 들어올 때까지 안내 메시지를 반복 출력합니다.
- **안전 종료:** 실행 중 `Ctrl+C`(KeyboardInterrupt)나 입력 종료(EOFError)가 발생하면, 안내 메시지를 출력하고 현재 데이터를 `state.json`에 저장한 뒤 안전하게 종료합니다.
- **파일 예외:** 파일 없음→기본 데이터 시작, 손상→기본 데이터 복구 (`try/except`).

## 데이터 파일 설명 (state.json)
- **경로:** 프로젝트 루트의 `state.json` / **인코딩:** UTF-8
- **역할:** 퀴즈 목록·최고 점수 저장으로 데이터 영속성 제공
- **저장 시점:** 퀴즈 추가·점수 갱신·안전 종료 시 자동 저장
- **스키마:**
```json
{
    "quizzes": [
        {
            "question": "문제 내용",
            "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
            "answer": 2
        }
    ],
    "best_score": 1
}
```
- `best_score`는 미플레이 시 `null`.
- **JSON 선택 이유:** 사람이 읽기 쉽고, 퀴즈 목록+점수 같은 중첩 구조를 그대로 표현할 수 있어 CSV보다 적합하며, 표준 `json` 모듈로 추가 설치 없이 처리됩니다.
- **저장 실패 시:** 쓰기 오류(OSError) 발생 시 안내 메시지를 출력하며, 데이터는 다음 저장 시점에 다시 기록됩니다.
- **백업/복구 전략:** 손상 시 기본 데이터로 복구합니다. 데이터 보존이 중요해지면 저장 전 기존 파일을 `state.json.bak`으로 복사하는 백업 절차를 도입할 수 있습니다. (확장 여지)

## 확장성 (대량 데이터)
- 현재는 퀴즈를 메모리 리스트로 관리하여 수백 개 수준은 무리 없습니다.
- 1,000개 이상으로 커지면 전체 로드·전체 저장 방식이 느려질 수 있어, SQLite 등 DB나 부분 저장·인덱스 검색 도입을 고려할 수 있습니다. (확장 여지)
